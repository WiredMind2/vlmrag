# Definition of done

A story is not Done until every acceptance criterion in its item file is checked, and every box below is checked for that story.

- [ ] The item status is `Done`
- [ ] Every acceptance criterion is checked
- [ ] Numbers and paper claims in the docs cite a source, or are marked as a project decision
- [ ] A documentation story did not add training, evaluation, or model-loading code
- [ ] `docs/work/README.md` still lists the item
